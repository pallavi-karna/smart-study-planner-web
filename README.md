# Smart Study Planner

A web-based study planner that helps students organize tasks, manage deadlines, and improve study productivity.

---

## Project Overview

Smart Study Planner is a simple task management application designed for students.

Users can create study tasks, track deadlines, receive deadline warnings, and organize their daily study schedule through an easy-to-use interface.

---

## Features

- Add study tasks
- Edit existing tasks
- Delete tasks
- Deadline reminder system
- Deadline warning notifications
- Responsive user interface

---
